# Publish fixed form versions

Creators refine a form before publishing a fixed version to a public link. Jev participates in creation and editing; it does not choose new questions separately for each respondent in the initial product. Gibson accepted this recommendation on 2026-11-05 so creators can review what they are sending and compare answers against known questions.

Respondent-specific AI interviews would require a different model for question selection and answer comparison.

On 2026-11-05, Gibson also accepted the update model: edits to an already-published form remain a draft until the creator explicitly selects Publish update. Publishing preserves the public link. Each submission retains its original form version, including the question wording, so replacing a field cannot silently reinterpret historical answers. This requires preserving published versions instead of overwriting their definitions.

Gibson accepted simple configured branching and pinning each open respondent session to the version initially loaded. New visitors receive the latest published version, while respondents already answering may submit against their original version. Form closure stops submissions across versions and displays a clear closed message at the public link.
